新增深色作战台控制台：任务中心与情报中心，主导航收敛为这两页，运行详情与诊断作为辅助页。

- `web/static/console.css`：深灰蓝底、低饱和面板、青蓝主操作色，左侧导航 + 顶部状态栏 + 12 列栅格。
  **状态从不只用颜色表达**：每个状态徽标都同时带字形与文字，色盲与灰度下仍可读。
- `templates/missions.html`：统计瓦片、多区段任务表单（起止坐标、出发星球、舰队预设）、历史任务列表。
- `templates/intel.html`：顶部紧凑筛选条 + 下方宽列表 + 详情弹窗。
- `dry run` 只作为锁定徽标展示，**界面不提供开关**；真实派遣仍只能走既有 Canary 流程。

按反馈调整的几处：

- **筛选区紧凑化**（笔记本小屏）：标签内联而非堆叠，根条件组的 AND/OR 并入工具行且不再画边框，
  条件区可折叠。面板高度 191px → 144px。
- **列表列**：只保留 深空吞噬者 / 噬能截击者 / 钛能守卫者 / 收割者 四列（`web/display.py`
  的 `LIST_SHIP_COLUMNS`），其余归入「其他舰种」汇总列并在详情中展开。
  每种舰种一列会让表格宽过任何笔记本屏幕。
- **缺失即 0**：快照未列出的舰种显示 0，而不是留空让人去解读。
- **数值列居中**，表头带相同对齐类，列名压在自己的数字上方。
- **表头锁定**：`.table-wrap` 自身双向滚动，`position: sticky` 因此吸附在表格而非页面，
  短屏滚动时列名始终可见。
- **详情弹窗**：默认展示最新快照，有历史时可用下拉切换，并对相邻快照逐舰种显示增减。

同时按用户提供的游戏内目录配置了完整舰种表（`SHIP_ORDER` 18 项 + `DEFENCE_ORDER` 11 项，
按游戏顺序保存）。这纠正了此前猜测的名字：`运输舰`→`小型运输船`、`间谍探测器`→`探测器`，
并补入 `收割者`、`湮灭之星`、`行星际导弹`、`拦截导弹`、`太阳能卫星`、`小型护盾`、`大型护盾`。
`GET /api/intel/ships` 改为按游戏顺序返回；目录外但已记录的名称仍追加返回，不会消失。
