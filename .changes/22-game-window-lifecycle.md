游戏窗口不在时自己拉起来，并修掉一个会静默抓错窗口的缺陷。

用户随时会关掉游戏、切换登录、或把窗口最大化。无人值守的运行必须能自己恢复，
而不是发现窗口不见了就失败。

- `game/game_window.py`：`ensure_game_window()` 找不到窗口就用 `--app` 模式拉起，
  轮询等它出现，还原最大化状态后调到标定视口。视口对不上标定值就抛错——
  几何不对时继续截图只会喂给解析器错位的 ROI。
- `ViewportPlan` 把「页面视口 → client → window」的换算收在一处：
  视口 1920×879 + 标题栏 38 + 边框 (18, 9) = 窗口 1938×926，实测可精确命中。

**修掉的缺陷：`find_window("EVO")` 会匹配到本地控制台。** 控制台页面标题是
「情报中心 · EVO-Helper」，含 `EVO`，按子串匹配会命中它——于是把控制台的像素喂给游戏解析器，
而且表面上一切正常。本次会话已实际踩到（先是抓到控制台窗口，后来两个窗口同时匹配才报错）。
`find_game_window()` 改为**精确**标题匹配。

**实机验证**：关掉游戏窗口后调用 `ensure_game_window()`，3.5 秒自动拉起，
视口精确回到 1920×879。
